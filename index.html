UNDERSTANDING

AI是什么：不是一个软件，而是一类技术

AI不是某一个App，而是"让机器能做通常需要人类智能的事"的技术总称。我们今天用的"大模型"，是AI目前最厉害的一个分支。

METAPHORS

三个比喻：一秒懂AI

不讲技术原理，用三个比喻让你理解AI到底是什么、能干什么、不能干什么。

📚读过万卷书的实习生

优点：知识量巨大、随叫随到、不知疲倦
缺点：没常识、没经验、会犯错
启示：它给的答案，你要检查

🦜超级聪明的鹦鹉

本质：学的是语言规律，不是真正理解意思
表现：能模仿各种风格，但不知道自己在说什么
启示：喂给它的素材和例子很重要

🎯蒙题高手（最重要）

本质：AI是在"猜"下一个词，不是在"想"答案
规律：题目出得好，蒙对概率就高
启示：不是AI不行，是你不会出题

一句话真相：AI是工具，你是大脑。AI负责"干活"，你负责"判断"。AI是概率的艺术家，不是逻辑的数学家。

TECHNOLOGY

大模型是什么：先训练出能力，再用于具体任务

不用懂技术，但要知道它怎么工作——这决定了你该怎么用它。

🏋️训练阶段：读遍全网

大模型在训练阶段从海量数据中学习规律——语言表达、关联关系、常见结构。就像一个读遍了全网书籍的"超级实习生"。

关键点：训练是一次性的，训练完之后模型就固定了，它不会在你聊天时"学习"新知识。

💬使用阶段：结合你的输入

你每次提问，模型结合你这次的输入（提示词+上下文）生成结果。同一个模型，给不同的材料，就会给出不同的回答。

关键点：你给什么，比它是什么更重要。这就是为什么"提示词"和"上下文"如此重要。

定义参考：斯坦福大学HAI研究所 / CS124课程
大模型 = 经过大规模训练、用大量参数表示所学规律的计算模型。
CAUTION

它为什么会"一本正经地胡说"？

这是宣传岗最需要知道的事——AI不知道答案的时候，不会说"我不知道"，它会编一个看起来很合理的答案。

专业名词：幻觉（Hallucination）

因为AI是"蒙题高手"，它的目标是"生成看起来最合理的下一个词"，而不是"生成正确的答案"。所以它会特别自信地编造事实、数据、引用。

记住：AI给的事实、数据、引用，必须交叉验证。特别是政策名称、数据数字、人名职务——错一个，发出去就是事故。

🛡️防幻觉三招

1. 给材料：把政策原文、真实素材喂给它，让它基于材料回答

2. 划边界：告诉它"只基于我给的材料回答，材料没写就说未提及"

3. 必核实：重要信息（数据、人名、政策名）发布前必须查原文

CAPABILITY

AI能帮宣传工作做什么？从六个环节看

从选题到发布，每一步都可以有AI搭把手。但记住——AI搭把手，你是掌舵的。

🔍找

找素材、找资料、找政策原文。以前搜半天，现在让AI帮你整理。

📋理

整理素材、提炼要点、做会议纪要。一堆材料丢给AI，它帮你理出头绪。

✍️写

写新闻稿、写公众号、写政策解读、写标题。这是AI最擅长的，也是你们最耗时的。

🎨画

做海报、做信息图、做公众号封面。你说，它画，不用求设计。

🎬剪

做短视频脚本、加字幕、配音、一键成片。一个人半小时出一条政策短视频。

📤交

一稿多渠道分发、排版适配、发布检查。同一篇稿，AI帮你改成四个平台版本。

SECURITY

每次用之前，先过这四道门

对海关来说，AI的第一课不是"怎么用"，是"什么不能喂"。红线不破，技巧才有意义。

1

保密关

企业申报信息、内部文件、未公开数据、执法信息——一旦进了AI，你就不受控制了。
先过保密关，再谈效率关。

2

真实关

AI合成画面永远不能冒充新闻照片。海关新闻讲究现场、真实、可追溯。
AI可以做"设计"，不能做"证据"。

3

审核关

AI写的稿子不署名，署名的是你。数据错一个、口径偏一点，追责追的是人。
AI出初稿，人工做终审。

4

来源关

政策类内容必须先查官方来源，绝对不能让AI自己编政策。查不到完整的，就用已确认的。
先有确定证据，再落地图片或文章。

对企业来说，AI是效率工具；对海关宣传口来说，AI是"效率工具 + 风险源"。用好了是助手，用错了是事故。
AGENT SECURITY

用Agent的最大风险：不是写错字

海关宣传口用AI，最大风险不是"AI写错字"，而是泄密、发布失守、责任说不清。AI定位是辅助工具，不是全自动发稿系统。

🔒1. 泄密：最不能出的事

Agent要读材料、拆任务、调工具。一旦把内部文件、案件线索、企业数据、查验信息喂进公共AI，就可能传到互联网平台。

哪怕删了企业名称、价格、数量，AI也可能靠关键词拼出完整敏感信息——"拼图式泄密"很真实。

红线：涉密、工作秘密、敏感信息，不进未审批的公共AI。

📋2. 审查流程被绕开

宣传口有铁规矩——先审查、后公开，一事一审。但Agent容易让人产生错觉："反正最后有人审。"

实际风险：AI先起草、改写、排版、分发，人工只扫一眼。中间漏掉口径错误、敏感细节、未经授权的内部信息。

Agent可以整理初稿，定稿发布必须走原审批流程，修改过就要重审。

⚠️3. 内容出错，砸公信力

AI会一本正经地编。有案例：干部让AI写材料，4个案例2个张冠李戴、2个凭空捏造。

放到海关宣传里更麻烦——政策口径、通关数据、处罚表述、企业名称、时间地点，只要错一处，就不是普通笔误，而是影响政府信息的权威性。

重要信息必须交叉验证，查原文、看来源。

©️4. 版权和人物权益

AI生成的图片、声音、视频也可能踩线。比如用了没授权的素材，或AI模仿了某人的声音肖像。

政务账号尤其敏感——泄露的不只是个人权益，更是政府公信力。账号外包出去，责任也甩不出去。

AI生成内容发布前必须确认素材授权和肖像权。

🤖5. 过度依赖，削弱判断

Agent用顺了，容易从"AI辅助"滑向"AI代笔"。最后稿子看着专业，但缺一线调研、少业务把关。

官方也提醒过，AI无法替代真实的社情民意，盲目依赖还可能助长形式主义。

AI是工具，你是大脑。判断力和创造力才是核心竞争力。

⚖️6. 出了事，责任算谁的？

这是关键。AI不会担责，最后追的还是使用的人、审核的人、发布的人。

所以Agent的每个动作都要留痕：输入了什么、调用了哪个Skill、生成了什么版本、谁审核、谁批准发布。否则一出问题，很难复盘。

全程留痕，谁审核谁负责。

记住三句话：
涉密内容，绝对不进公共AI。
AI只干初稿，人工负责核验。
发布前必须走原审批流程。

✅ 允许用 vs ❌ 禁止用 场景清单

✅ 可以放心用AI

✓ 公开政策文件的解读和大白话翻译
✓ 公开活动的新闻稿初稿撰写
✓ 公众号标题、文案的多方案 brainstorm
✓ 海报、图解等设计品的创意方案
✓ 已公开数据的整理和可视化
✓ 会议纪要的整理和提炼（公开会议）
✓ 学习资料、培训材料的辅助准备
✓ 错别字、语法的初步校对

❌ 绝对不能用AI

✗ 涉密文件、内部工作秘密的处理
✗ 企业申报数据、查验信息的输入
✗ 未公开的政策、人事、案件信息
✗ AI生成内容直接当新闻照片发布
✗ 跳过审批流程直接发布AI产出
✗ 让AI代替人工做最终审核决策
✗ 用AI模仿特定人物的声音/肖像
✗ 把AI输出当权威数据不做核实

REAL CASE

真实案例：从青铜到王者

用8月28日青浦真实举办的"e企聚势·数智扬帆"企业出海沙龙做案例。同一个AI、同一个任务，三种提问方式，三种完全不同的结果。

🥉 青铜 · 普通人随便说

"帮我写个宣传稿"

帮我写一篇企业出海沙龙的新闻稿
结果：AI先查出海趋势，给了一篇全是【】占位符的填空模板，还列了需要补充的信息清单。

能用吗？不能用，全是空格。
🥈 白银 · 提示词工程

用公式说清楚

你是10年经验政务新闻编辑。写一篇"e企聚势·数智扬帆"企业出海沙龙新闻稿：600字，分三段，语气客观严谨，突出跨境电商和政策支持。
结果：有了具体政策数据（178个综试区、跨关区退货模式、离境即退税），但活动具体信息（日期、地点、嘉宾）还是【】。

能用吗？能用了，但像模板，没有灵魂。
🥇 王者 · 上下文工程

公式 + 完整背景素材

公式 + 完整活动素材：时间8月28日、地点青浦e通世界产业园、主办青浦区新联会+e通世界产业园、7场分享嘉宾姓名职务、企业反馈...
结果：直接出完整成品，所有信息填好，有具体嘉宾内容，AI还诚实说明"素材中没提到青浦海关，所以通过综保区职能体现，没有虚构内容"。

能用吗？能直接用，有细节、有温度、有高度。
同一个AI，同一个任务，三次输出，天差地别。
差别在哪？不是AI变了，是你给的信息变了。
提示词工程告诉你"怎么说"，上下文工程告诉你"说多少"。

CONTEXT ENGINEERING

上下文工程：给AI配齐背景材料

提示词管"这一次说什么"，上下文管"它长期记得什么"。复杂任务里，AI缺的不是聪明，是信息没给够。

"别只改提示词，要设计AI周围的完整信息环境。"
—— 斯坦福大学2026年CS224G新课 · 上下文工程

🤢上下文腐烂

现象：给AI塞的资料越多，它反而越记不住重点
比喻：吃太饱，消化不良
建议：一次只喂需要的，资料少而精

🙈中间迷失

现象：长上下文中，放在中间的信息最容易被忽略
比喻：电梯汇报，先说结论
建议：最重要的指令放最前面，其次放最后

🔄回退清理

现象：聊岔了继续纠正，AI会越纠越偏
比喻：炒糊了重新起锅
建议：发现跑偏，回到出错前重开一条线

提示词错了只影响这一次，上下文错了影响之后每一次。
打个比方：提示词是你今天交给员工的活儿；上下文是这个员工的"岗位说明书 + 工作笔记 + 资料柜"。
GROWTH

从一句话到数字员工：Prompt、Skill、Agent

AI的用法有三个层次，今天学的是第一层，但后面两层要知道方向。

LEVEL 1

Prompt 提示词

一次性的任务交代。每次跟AI说话，用公式说清楚。适合一次性的、不重复的任务。

→
LEVEL 2

Skill 技能

把固定流程封装成"技能包"。一次写好，反复调用。适合重复、流程固定、输出统一的任务。

→
LEVEL 3

Agent 智能体

会自己拆任务、调资源的"数字员工"。你给目标，它自己安排先做什么、后做什么。适合多步推进、中途要判断的复杂任务。

✅适合做Skill的活

三个特点：重复、流程固定、输出格式统一
比如：周报、会议纪要、海报文案、视频字幕、政策问答初稿

✅适合上Agent的活

三个特点：多步推进、中途判断、多工具切换
比如：跨部门素材收集、长报告生成、多平台内容分发

好记的版本：固定动作做Skill，复杂流程上Agent，重复工作靠上下文工程喂好材料，提示词工程保证每次都说得清楚。
PERSONALIZATION

让AI认识你，比学会十个技巧都管用

用AI之前，先让AI认识你。给它做一次"入职培训"，以后配合就顺畅了。花10分钟做这个，换以后几百小时的省心。

📝 给AI的入职说明：写清这六点

1. 你是谁
AI的角色定位
2. 我是谁
你的身份和岗位
3. 读者是谁
目标受众
4. 风格是什么
语气、禁忌词
5. 输出格式
字数、结构、标题数量
6. 安全红线
什么信息不能用
💡 在哪里设置？
豆包APP/网页版 → 我的 → 设置 → 自定义指令（或"偏好设置"）
把上面六点写进去，以后每次对话AI自动记住，不用重复说。
DESKTOP AGENT

WorkBuddy和豆包工作：两个能直接干活的工具

前面的AI都是"动嘴"：给你答案、给你图、给你视频。但桌面智能体——动手。它跑在你电脑上，你一句话，它自己打开文件、自己点鼠标、自己把成品存好。

💼WorkBuddy（腾讯）

推出时间：2026年3月
核心能力：处理本地文件，授权后直接读写你电脑上的文件夹
擅长：批量改文件名、整理表格、做PPT、分析数据
特色：支持微信远程指挥

🖥️豆包工作（字节）

推出时间：2026年8月上线"虚拟桌面"
核心能力：AI在独立后台桌面里自己动鼠标，不抢你眼前的屏幕
擅长：打通飞书、钉钉200多个技能
特色：人在外面，可用手机远程指挥家里电脑干活

桌面智能体的规矩：你交代、它执行、你审核。
政务场景记住：整理公开材料可以，涉密文件别让它碰。授权要最小——只给它"允许碰的文件夹"，就像家里请保洁，只给需要打扫的房间钥匙。
MINDSET

AI时代的能力素养

工具会换，但有些能力永远不会过时。这是用好AI的底层素质。

🎯

目标感

知道自己要什么，才能让AI帮你做什么。目标越清晰，AI输出越精准。

📝

表达力

能把需求说清楚的人，才能用好AI。提示词的本质是清晰表达。

🔍

判断力

AI给的是初稿，你是终审。能分辨对错、好坏，才是核心竞争力。

🔄

迭代力

一次不行就改，改到满意为止。跟AI合作是一个反复迭代的过程。

🛡️

底线感

知道什么能做、什么不能做。保密、真实、审核——红线不破。

📚

学习力

AI每天都在变，保持好奇、持续学习。今天学的是方法，不是某个工具。

AI PARTNER SETUP

创建你的AI工作伙伴

花10分钟给AI做入职培训，换以后几百小时的省心。推荐WorkBuddy和豆包工作同时用，都有算力扶持。

🎯为什么要做"入职培训"？

大家想想，你们单位新来一个实习生，你会怎么带他？第一天，你会告诉他：你是谁、我是谁、咱们科室干什么活、什么标准算合格、遇到事怎么跟我汇报、什么事必须先问我。对吧？你不会第一天就把一堆活扔给他，说"你自己看着办"。AI也是一样。

核心理念：不要"入职定终身"，要"边用边养"。今天打个底，以后慢慢调。不要把AI框死，给它留点空间，它会给你惊喜。

💡 两个工具同时用，都有算力扶持：
WorkBuddy（腾讯）——处理本地文件强，微信远程方便
豆包工作（字节）——虚拟桌面不抢屏，飞书技能多，手机远程指挥

🎤标准版：AI入职面试官提示词（推荐）

把下面这段提示词复制到WorkBuddy或豆包工作，AI会自动采访你，最后帮你整理成说明书+精简版设置。

# 角色 你是一位专业的"AI工作伙伴入职面试官"，专门帮助政务宣传口的工作人员，通过对话采访的方式，梳理出一份个性化的"个人AI工作伙伴说明书"。 # 你的任务 通过6个方面的提问，帮助我想清楚：我是谁、我干什么活、我要AI帮我做什么、什么标准算合格、我们怎么沟通、什么事必须我把关。 # 采访规则（非常重要） 1. 一次只问一个问题，等我回答后再问下一个 2. 每个问题开头，先用一句话说明"为什么问这个问题" 3. 如果我的回答太模糊，可以追问1-2个具体问题 4. 不要替我回答，不要编造我的信息 5. 全程用轻松、鼓励的语气，像朋友聊天一样 # 采访框架（6个方面） 1. 认识你：岗位和日常工作、服务对象是谁 2. 工作内容：最常写的三类内容、最耗时头疼的事 3. AI帮你做什么：如果只能先帮一件事，最希望是什么 4. 你的标准：合格的新闻稿/公众号推文是什么样 5. 怎么沟通：任务不明确时先问还是先做、多步骤怎么汇报 6. 权限边界：哪些事AI绝对不能自己做主 # 采访结束后 整理成两份： 1. 完整版《个人AI工作伙伴说明书》 2. 精简版（500-800字，可直接复制到自定义指令） # 现在开始 先做个简单的自我介绍，然后问第一个问题。

📝政务宣传口·自定义指令参考模板

不想被AI采访？直接复制下面这个模板，修改成自己的信息，粘贴到WorkBuddy或豆包工作的"自定义指令"里。

我是青浦海关宣传科工作人员，主要负责新闻宣传、新媒体运营和政策解读。你是我的AI工作伙伴，协助我完成宣传工作。 【你的角色】 - 有10年政务宣传经验的助手，熟悉海关业务和政务写作规范 - 了解青浦海关特色：进博会、综保区、跨境电商、AEO认证等 【你擅长的工作】 1. 整理素材：把活动记录、会议纪要、企业反馈整理成结构化素材 2. 生成初稿：新闻稿、公众号推文、政策解读的初稿 3. 优化辅助：改标题、调结构、润色语言、查错别字 【输出标准】 - 新闻稿：600-800字，三段式，客观严谨，用数据说话 - 公众号推文：口语化标题，短段落，结尾有互动 - 政策解读：要点提炼+大白话解释+企业怎么办 - 不用"重磅""震惊"等夸张用语，不用网络梗 【沟通规则】 - 任务不明确时，先问3个关键问题再动手 - 涉及企业名称、数据、政策口径，必须提醒我核实 - 多步骤任务每完成一步汇报进度 - 发现我的要求有问题，必须直接指出来 【权限边界】 - 可以直接做：整理素材、生成初稿、改错别字、调格式 - 必须先确认：删除文件、修改已审核稿件、任何对外发送 - 绝对不做：替我审批、替我回应舆情、编造数据、泄露内部信息 【安全红线】 - 内部文件、未公开数据、企业商业秘密，不输入不传播 - AI生成的图片/视频，不冒充新闻现场照片 - 所有对外发布内容，必须走三审三校 - AI生成内容必须标注"AI生成" 【不要自我设限】 除了上面说的工作，遇到其他任务你也可以尝试。能做的就做，做不了的告诉我。
