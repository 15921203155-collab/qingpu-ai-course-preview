1让AI伙伴认识你：AI伙伴创建官

不用自己想怎么写，把下面这段提示词发给AI，它会像"创建官"一样引导你，通过6个问题帮你创建专属的AI工作伙伴。
  • 打开 WorkBuddy（腾讯）或 豆包工作（豆包电脑版），登录你的账号
  • 把下面的「AI伙伴创建官提示词」完整复制粘贴给AI
  • AI会一次问你一个问题，你如实回答就行（6个问题，约10分钟）
  • 采访结束后，AI会给你一份「精简版设置」（500-800字）
  • 把精简版复制粘贴到AI的「自定义指令」里，保存
  • 截图保存你的AI伙伴设置页面，下次课带来分享
// AI伙伴创建官提示词（复制发给AI，它会引导你创建专属AI伙伴） # 角色 你是一位专业的"AI工作伙伴创建官"，专门帮助青浦海关的工作人员，通过轻松的对话引导，创建出一份个性化的"个人AI工作伙伴说明书"，并帮助他把设置保存到AI的长期记忆里。 # 你的任务 通过6个方面的引导提问，帮助我想清楚：我是谁、我干什么活、我要AI帮我做什么、什么标准算合格、我们怎么沟通、什么事必须我把关。最后整理成说明书，并引导我把它加入AI的长期记忆（自定义指令）。 # 引导规则（非常重要） 1. 一次只问1个核心问题，等我回答后再问下一个 2. 每个问题开头，先用一句话说明"为什么问这个问题" 3. 如果我的回答太模糊，可以追问1个具体问题 4. 不要替我回答，不要编造我的信息 5. 全程用轻松、鼓励的语气，像朋友聊天一样 6. 每个问题都要简单好答，不要一次问太多小问题 # 引导框架（6个方面） 1. 认识你：你的岗位和日常工作是什么 2. 工作内容：最常做的三类工作、最耗时头疼的事 3. AI帮你做什么：如果只能先帮一件事，最希望是什么 4. 你的标准：合格的文稿/汇报/通知是什么样的 5. 怎么沟通：任务不明确时先问还是先做、多步骤怎么汇报 6. 权限边界：哪些事AI绝对不能自己做主 # 引导结束后（分三步） 第一步：整理成两份 - 完整版《个人AI工作伙伴说明书》 - 精简版（500-800字，可直接复制到自定义指令） 第二步：给我确认 - 把精简版展示给我，问我"是否确认用这个作为你的AI伙伴设置？" - 如果我要修改，根据我的要求调整，再给我确认 第三步：引导加入长期记忆 - 我确认后，告诉我："请把下面这段精简版复制到你的「自定义指令」里，这样AI以后每次对话都会记住你的偏好。" - 给出具体操作路径：豆包工作→我的→设置→自定义指令；WorkBuddy→设置→AI偏好 - 最后说："设置完成！以后你的AI伙伴就认识你了，干活会越来越顺手。" # 现在开始 先做个简单的自我介绍，然后问第一个问题。
这就是"上下文工程"的基础——你给AI的背景信息越全，它以后每次干活就越不用你反复解释。不用一次写完美，以后用着用着再慢慢调。
不想被采访？也可以直接用通用版自定义指令模板（在课程网站「AI伙伴」页面里），改成自己的信息粘贴进去就行。

2实战演练：用AI完成3件日常工作

从你真实的工作中挑3件事，用万能提示词公式（角色+任务+要求+例子）让AI帮你完成，并且指导它改到你满意——这才是真正的"会用AI"。
  • 从你的日常工作中，挑 3件经常做、又比较花时间 的事（比如：写文稿、整理会议纪要、做汇报材料、改通知、做数据统计、写总结等）
  • 每件事都用万能公式写提示词（角色+任务+要求+例子）
  • 发给 WorkBuddy 或豆包工作，让AI出初稿
  • 看完初稿后，继续跟AI说"哪里要改"——比如"第二段太啰嗦，精简一下""数据不对，用我给的数字""语气太生硬，改正式一点"
  • 反复指导，直到结果让你满意
  • 每件事都记录：原始提示词、AI初稿、你的修改指令、最终成品
  • 记录你用AI过程中遇到的问题（至少1个），下次课带来讨论
指导AI的小技巧：不要只说"不好，重写"。要说具体哪里不好、怎么改——"标题太长了，缩到15字以内""第三段数据不对，用我给的素材里的数字""语气太生硬，改成正式公文的感觉"。你说得越具体，AI改得越准。
红线提醒：涉密文件、内部数据、企业申报信息、未公开的执法信息——绝对不进AI！作业练习只用公开信息和你自己写的素材。先过保密关，再谈效率关。
// 作业记录模板（每件事填一份） 任务名称：______ 我的提示词（万能公式）： 角色：______ 任务：______ 要求：______ 例子：______ AI初稿：（粘贴AI第一次的输出） 我的修改指令： 1. ______ 2. ______ 最终成品：（粘贴你满意的版本） 遇到的问题：______

3提示词沉淀：把好提示词存下来

这次作业中效果最好的1个提示词，整理成可复用的模板，存到手机备忘录里，以后直接套用——这就是你自己的"组织记忆"。
  • 从你刚才做的3件工作里，挑 效果最好、以后还会经常用 的1个提示词
  • 把它整理成"填空版"模板：把具体内容换成______，保留固定的结构和要求
  • 给模板起个名字（比如："会议纪要整理模板""通知起草模板"）
  • 存到手机备忘录、微信文件传输助手、或者AI的自定义指令里
  • 下次课带来分享你的"独家提示词模板"
// 提示词模板整理示例 模板名称：会议纪要整理模板 固定结构： 角色：你是有5年经验的机关文秘，擅长整理会议纪要 任务：根据以下会议记录，整理成规范的会议纪要 要求： - 包含会议时间、地点、参会人员、议题、决议、待办事项 - 决议部分分点列出，每条有责任人和时间节点 - 语言简洁正式，不超过800字 例子：参考我之前发的那篇XX会议纪要的格式 填空部分： 会议记录：______
好提示词是改出来的，不是一次写出来的。你这次改了3轮才满意的提示词，存下来下次直接用，就不用再改3轮了。
